# V2.12.6 — 离线批量语义测评与质量门禁

> **离线组件，不是交易风控门禁。** 仅处理调用方传入的标注和已保存的 Reviewer 报告。本阶段没有任何真实模型调用、真实人类标注数据、真实行情数据或成本实测。

## 使用方式

```go
metrics, err := semanticreview.EvaluateRun(dataset, capturedRun)
gate, err := semanticreview.CheckQuality(dataset, capturedRun, policy)
```

`EvaluateRun` 不联网，不读取 API Key，不执行 Reviewer；将同一 `EvaluationDataset` 的多个样本与**某一次离线捕获的模型运行**逐条对齐。不同 `model_id` 或提示词版本可分别运行后比较结果，但本组件不会代替调用方建立模型或执行网络请求。

### Dataset 输入

`EvaluationDataset` 包括：
- `version`：不可为空的测评版本。模型预测包必须携带完全匹配的 `dataset_version`，避免跨版本数据混用。
- `provenance`：`SYNTHETIC`（合成）或 `HUMAN_REVIEWED`（人工已审核，**由调用方声明**）。
- `samples[]`：唯一 `id`、完整 `tasks`（已有 V2.12.3 的 `Tasks`）、按任务原顺序排列的独立 `gold`（已有 `GoldLabel`）。
- `HUMAN_REVIEWED` 样本必须提供非空 `evidence_ref`，以及两个不同的 `annotator_ids`。本库只检查**字段结构与唯一性**，不能验证标注员真实身份、实际是否独立标注、证据文件是否存在或结论是否正确；真正的人工标注治理需由调用方完成。

**严禁**从同一次模型的预测 `report` 自动生成 GoldLabel。此前的 `testdata/gold_v1.json` 只含虚构示例，不属于真实验证材料。

### Run 输入

`EvaluationRun` 包括 `dataset_version`、`run_id`、`model_id` 与和 Dataset **数量、样本 ID、顺序严格一致**的 `samples[]`。每个预测二选一：

1. `report`：必须能通过原有 `ValidateReport` 完整核验。
2. `failure_code`：只能是 `TIMEOUT`、`MODEL_ERROR`、`INVALID_REPORT`，此时不得同时提供 `report`。

`failure_code` 是**服务不可用**，不会被伪装为 `UNCERTAIN`。`UNCERTAIN` 只来自模型明确提交的合法 Finding。

`latency_ms`、`input_tokens`、`output_tokens` 都是可选的**外部实测值**，没有值时不得使用 0 填充。Token 必须成对给出且不得为负；输出记录 `observed_latency_count` 和 `observed_token_count`，防止把部分指标覆盖当成全部覆盖。P95 延迟仅由实际提交的非负延迟使用 nearest-rank 计算。**不推测 Token 单价或美元成本**。

### 指标与门禁

`EvaluateRun` 输出：完成 / 不可用样本数、总标注项数、实际评估项数、精确一致项数、模型 `UNCERTAIN` 数，以及将 **CONTRADICTORY 误标为 CONSISTENT** 与反向误判的数量。数据不满足严格对齐直接报错，不返回部分“看似正常”的评分。

`CheckQuality` **直接从原始 Dataset/Run 重新计算分数**，不会接受外部改写的 metrics；门槛来自调用方提供的 `QualityPolicy`：
- `min_labeled_items`（正整数）；
- `min_availability_bps`（0–10000，每 10000 为 100%）；
- `min_exact_match_bps`（同上，分母为真正有报告的 Item）；
- `max_false_consistent_on_contradictory`（非负整数）。

返回 `PASS`、`FAIL`、`NOT_ELIGIBLE`，附稳定的失败原因及实际指标。**合成样本只能得到 `NOT_ELIGIBLE`**；声称人工审核但样本数量不足或没有可计分结果亦不能得到 PASS。小样本和低完成率不能拿高精确度掩盖：覆盖率和样本数量由策略分别限制。

`HUMAN_REVIEWED` 是调用方自报来源属性，因此即使输出 `PASS`，也只表示**这些输入数据符合设定的离线阈值**，不是“模型已被独立认证”，更不是生产部署许可。

## 下一项真实测评前置条件

真正做准确性、误判率、延迟和费用对比前，需收集独立、可溯源、时间点正确的研究样本；实现盲标、双人独立标注与分歧仲裁，冻结测试集版本，保留有成本与延迟遥测的模型运行记录，并用未参与调参的 holdout 集进行复测。

本阶段只通过合成/模拟数据验证算法与校验边界，**没有真实 LLM 质量结论**。

## 不影响既有链路

本实现没有修改 `FullPortfolioWorkflow`、`PortfolioReview`、`RiskContext`、`PortfolioDecision` 或 CLI，没有调用外部 API，更没有增加真实交易或订单能力。离线评估门禁**不自动阻止/授权研究结果**。
