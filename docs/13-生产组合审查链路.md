# V2.10 生产研究链路：ResearchArtifact → PortfolioReview

> 接入版本：PR #81。这里描述实际可调用的业务路径，而不是 Hosted E2E 的测试行为。

## 目标与职责

```
Market + Technical + Event
             ↓
      Synthesis → validated ResearchArtifact
             ↓
         Bull/Bear Debate
             ↓
        Research Manager
             ↓
      Trading Agent → TradeIntent
             ↓
      General Risk Analyst → RiskContext
             ↓
      Portfolio Manager → PortfolioDecision
```

- Market、Technical、Event、Synthesis 在一个 `NewArtifact` 图内执行，每轮只执行一次。
- `PortfolioReview` 必须消费同一次运行真实生成且经过验证的 ResearchArtifact，不得把 Hosted fixture 当作市场/组合输入。
- Legacy `research.New(...).Run(...)` 仍返回 Decision，保持原来的调用行为；`research.NewArtifact(...).RunArtifact(...)` 不运行 Trading Agent。
- `FullPortfolioWorkflow.Run(ctx,input,book)` 验证 PortfolioContext 和 PIT 时间，再执行上游研究与下游审查。
- 任意阶段报错即停止，不能返回伪造的 PortfolioDecision。
- 结果仅为研究和组合审查意见，不是可执行委托或资金授权。

## CLI：显式启用

旧模式保持不变（不传 `-portfolio-review`），继续返回旧 Decision。

完整 Research/Risk/Portfolio 模式必须同时传入：

```bash
go run ./cmd/aegis -symbol 600519.SH \
  -portfolio-review \
  -portfolio-file ./portfolio.json
```

### 未知账户（无账户数据源时）

`portfolio.json`：

```json
{"state":"NOT_PROVIDED"}
```

此状态明确表示账户信息未提供，**绝不是空仓**。对应 RiskContext 必须是 `INSUFFICIENT_CONTEXT`。这不是模拟持仓，也不产生交易批准。

### 已观测空仓

仅当用户真实确认了截至某时刻账户无持仓时，才可提交：

```json
{
  "state": "EMPTY",
  "as_of": "2026-10-08T09:00:00+08:00"
}
```

### 已观测持仓

以下仅展示**文件结构，不代表用户真实持仓**：

```json
{
  "state": "POSITIONS",
  "as_of": "2026-10-08T09:00:00+08:00",
  "positions": [
    {"symbol":"600519.SH","quantity":100}
  ]
}
```

账户数据必须由调用方提供，不得由 LLM 推测、凭空补全或从测试数据加载。CLI 对 JSON 使用严格字段解码（拒绝 unknown fields、多个 JSON 值），随后 `portfolio.Validate`。

`as_of` 使用 RFC3339 时区完整时间，不得晚于此次研究请求的截止时间。即使 PortfolioState 是 EMPTY 或 POSITIONS，也无法由目前的有限字段计算现金、净值、敞口、风险预算、可用购买额或可执行订单。

## 可执行和验收边界

`PortfolioDecision` 当前仅包含 `NO_ACTION`、`BLOCKED`、`REVIEW_REQUIRED`，无 BUY/SELL、下单数量/价格。

必须分别检查：
1. **单元/契约**：上游研究图单次执行；组合输入在任何模型调用前校验；PIT 快照不能来自未来；研究证据不完整时下游不执行。
2. **真实 Hosted**：原始 Live Event 数据源与 DeepSeek 真实交互；记录 commit SHA、时间、实际决策状态。不能用本地伪造 fixture 证明真实持仓判断能力。
3. **生产启动路径**：CLI `-portfolio-review` 实际装配研究图、Debate、Research Manager、Trading、Risk、Portfolio；明示账户文件，且不调用旧的 Decision 研究图重复运行。

目前不具备真实交易额度和风险约束，所以即使 RiskContext 是 ACCEPTABLE，Candidate 也只能 REVIEW_REQUIRED，不能升级为 APPROVED 或下单。

完整性和审计先于测试通过率。Event 相关性无法充分分类时应返回研究不完整错误，不能隐匿缺失新闻并继续生成“已完成”的投资判断。
