# 组合研究领域

组合研究使用 `internal/portfolio` 的确定性输入和计算。现有 `portfoliodecision.Decision` 继续记录单项研究处置，`risk.Context` 继续记录风险发现和引用。仓位研究后续使用独立输出对象，执行授权在系统范围之外。

## 观测、政策与派生值

| 对象 | 内容 | 时点与版本 |
| --- | --- | --- |
| `ResearchAccountSnapshot` | 账户 ID、持仓数量、可选估值及逐持仓总成本 | 账户快照版本、观察时间、来源引用与可用时间 |
| `ResearchRiskPolicy` | 既有限额规则，以及可选的声明亏损预算 | 政策 ID、独立版本、生效时点、来源引用与可用时间 |
| `ResearchAccountView` | 账户状态、持仓及成本、已观测敞口、独立预算和当前限额检查 | 输出结构版本、研究截止时间、账户和政策的版本及出处 |

`AssessResearchAccount` 使用既有验证器检查账户状态、估值金额守恒、快照时效和限额。账户与政策分别检查可用时间，取值范围从各自的观察或生效时间到研究截止时间。调用方可以明确指定账户快照的最大年龄。来源引用使用非敏感标识，来源认证由导入或供应商适配器负责。

货币使用人民币分，权重显示使用基点。估值只涵盖现金与明确估值的持仓，覆盖范围以外的资产、负债、保证金和冻结资金仍未知。没有持仓的账户可以有现金。零值账户的权重未定义。观察成本按当前持有数量记录总金额。估值、成本和预算分别保留缺失与显式零的区别。声明亏损预算由调用方提供，不能根据市值、现金或现有持仓推导。
